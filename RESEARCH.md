# Исследование перед разработкой

Проверено 2 ноября 2026 года. Сторонние скрипты не запускались; изучались публичные README, дерево и указанные файлы. Отсутствие в этих источниках публичного API не доказывает, что его не существует где-либо ещё.

## Документация и игра

- [Официальная страница BABFT](https://www.roblox.com/games/537413528/Build-A-Boat-For-Treasure): строительство, плавание и бонус золота группе; не документирует интерфейс размещения, инвентаря или покупок. [Неофициальная вики](https://roblox.fandom.com/wiki/Chillz_Studios/Build_A_Boat_For_Treasure) описывает магазин и товары за золото; актуальность цен не гарантирована. Подтверждённой автоматизации этих действий не найдено.
- [Roblox HttpService](https://create.roblox.com/docs/reference/engine/classes/HttpService.md): HTTP выполняется серверами опыта с включённым HTTP; показаны `RequestAsync`, `JSONDecode`, `pcall` и проверка результатов. Это не даёт внешнему приложению доступ к серверу BABFT. В нашем браузерном загрузчике независимо проверяются статус, ошибки, JSON и размер.

## Проверка этого проекта

- `npm run check`: синтаксис всех JS-модулей и 18 Node-тестов симуляции, в том числе искусственные HTTP-ошибки и отмена во время шага.
- Luau CLI 0.745: smoke-тест отключённого контракта адаптера; `luau-analyze` проверял контракт и тест. Это не проверка в Roblox Studio или BABFT.
- Chromium: локальная веб-страница на размерах 1440×1000 и 390×844; пример, расчёт ресурсов, завершение симуляции, скрытие панели, отсутствие горизонтального переполнения; в браузере проверена фактическая загрузка опубликованного примера с GitHub Raw. Фактические игровые действия не выполнялись.
- Форматирование проверено Prettier для JS, CSS, HTML, JSON и документации. CI запускает проверку Node; успешный запуск облачного CI отдельно не подтверждён.
