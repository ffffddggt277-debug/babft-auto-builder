# BABFT Auto Builder

Проверяемый **браузерный планировщик и симулятор** схем для Build A Boat For Treasure. Это не скрипт для запуска в BABFT и не модификация Roblox. Реального размещения блоков, доступа к инвентарю, золоту и покупкам нет: подтверждённого публичного интерфейса BABFT для этих операций в изученных источниках не обнаружено. Проект не связан с Roblox или Chillz Studios.

## Возможности

- Адаптивная панель, которую можно скрыть и вернуть; загрузка схемы по публичному GitHub Raw URL или вставкой JSON. Данные не исполняются как код.
- Строгая проверка входа, читаемые ошибки, ограничение размера и числа блоков. Поддерживается только **внутренний условный идентификатор** `wood`; он не является подтверждённым названием API игры.
- Проекция сверху X/Z с поворотом Y и порядок слоёв по высоте; наклоны X/Z не отображаются, коллизии и геометрия самой игры не моделируются.
- Расчёт количества блоков и нехватки относительно вручную введённого инвентаря, выбор порядка и скорости. Одна запись = один блок, независимо от размера.
- Асинхронная **локальная симуляция** с прогрессом, паузой, отменой и журналом; никаких действий в Roblox. Отмена ожидает завершения уже выполняемого шага.
- Безопасные отключённые интерфейсы GameAdapter/EconomyAdapter и отдельный контракт Luau; без предположений о RemoteEvent. Реализация разрешённого серверного API требует разрешения и кода владельца конкретного опыта.

## Быстрый запуск

Нужны Python 3 и современный браузер; Node.js 20+ — только для тестов. Клонируйте репозиторий и в его каталоге выполните:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`, нажмите «Загрузить пример» или вставьте публичный Raw URL, затем «Проверить и создать план». Введите число блоков, выберите порядок и нажмите «Начать симуляцию». GitHub Raw должен быть доступен браузеру и разрешать CORS; сеть, политики браузера или приватный репозиторий могут помешать загрузке. Не вводите токены или приватные URL. Для остановки локального сервера нажмите Ctrl+C. Не открывайте `index.html` через `file://`: браузер может блокировать ES-модули и загрузку примера.

## Формат схемы v1

Полный пример: [`examples/test_build.json`](examples/test_build.json). Все поля обязательны; неизвестные поля отклоняются. `position`, `size` и `rotation` — объекты с числовыми `x`, `y`, `z`; позиция — центр блока в условных единицах, поворот — градусы. Цвет — строка `#RRGGBB`. Размеры каждого измерения от 0.01 до 1000, координаты от -10000 до 10000, повороты от -360 до 360. Это формат **данного проекта**, не формат импорта BABFT; размеры, вращения, цвет и единицы не подтверждены как поддерживаемые игровой интеграцией. Макс. 2000 блоков и 1 000 000 байт JSON. Без проверки пересечений и устойчивости.

```json
{
  "version": 1,
  "name": "Пример",
  "blocks": [
    {
      "type": "wood",
      "position": { "x": 0, "y": 0, "z": 0 },
      "size": { "x": 2, "y": 1, "z": 2 },
      "rotation": { "x": 0, "y": 0, "z": 0 },
      "color": "#B68153"
    }
  ]
}
```

## Тестирование и диагностика

```sh
npm run check
# Необязательно, если установлен Luau CLI:
luau tests/adapter.luau
```

Тесты Node проверяют валидацию, JSON и сетевые ошибки через mock HTTP, подсчёт, порядок и состояние симуляции, включая паузу, отмену и отказ адаптера. CI выполняет `npm run check`. Результаты не подтверждают работу в Roblox или самой игре. Журнал доступен внизу страницы, сохраняется только в памяти вкладки; его можно скачать. Проверяйте, что Raw URL публичный и HTTP-запрос не блокируется CORS; при ошибках JSON проверьте описание поля. Не публикуйте журнал, содержащий чувствительные данные.

## Roblox и экономика

Официальная страница игры описывает постройку и плавание, упоминает бонус золота участникам группы. Неофициальная вики описывает магазин с предметами за золото, но её цены могут устареть. Ни один из этих источников не документирует публичный программный интерфейс инвентаря, покупки, заработка или размещения. Поэтому автоматизация золота и покупок отсутствует, как и интеграция с BABFT. Не предлагается обход проверок, подмена ответов или executor. `roblox/Adapters.luau` — только явно отключённый контракт, не установщик GUI и не рабочий плагин.

В собственной игре Roblox для получения JSON на сервере требуется включённый HTTP и `HttpService`; обычный внешний браузерный интерфейс данного проекта к игровому серверу не подключается. Любая будущая интеграция должна использовать только задокументированный и разрешённый владельцем API, проверять права и входные данные на сервере, не доверять клиенту и явно подтверждать реальные возможности каждого свойства. Не вставляйте секреты в репозиторий.

## Исследование и заимствованные идеи

- [Roblox HttpService](https://create.roblox.com/docs/reference/engine/classes/HttpService.md) — JSONDecode, RequestAsync/GetAsync на сервере, защищённая обработка ошибок и включение HTTP. Не предполагается доступ из чужого опыта.
- [Build A Boat For Treasure — официальная страница](https://www.roblox.com/games/537413528/Build-A-Boat-For-Treasure) — описание игры и бонуса золота. [Вики сообщества](https://roblox.fandom.com/wiki/Chillz_Studios/Build_A_Boat_For_Treasure) — контекст магазина; не официальный API.
- [Roblox/TestEZ](https://github.com/Roblox/testez) (Apache-2.0): отдельные `src`, `tests` и CI, фокус на автоматических тестах; среда выполнения отличается от браузера, код не заимствован.
- [Rojo](https://github.com/rojo-rbx/rojo) (MPL-2.0): файловая организация Roblox-проектов и развёртывание через инструменты разработки; не включён в проект, поскольку полноценный Roblox-плагин здесь не реализован.
- [Roblox Requests](https://github.com/pat-dill/roblox-requests) (MIT): явные HTTP-статусы, декодирование и ошибки; проект использует собственную минимальную реализацию `fetch`, код не копировался.
- [buildaboatAutoFarm](https://github.com/scarabhub/buildaboatAutoFarm) (Apache-2.0): один файл, README описывает executor и бесконечный цикл. Это не подтверждение официального API; такой способ и код не использовались. README не содержит доказательств автоматических тестов или обработки ошибок.
